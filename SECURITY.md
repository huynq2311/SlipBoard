# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of SlipBoard.

| Version | Supported |
| ------- | --------- |
| Latest stable release | ✅ |
| Older releases | ❌ |

Users are encouraged to keep SlipBoard updated to the latest available version.

## Reporting a Vulnerability

Security is important to SlipBoard, especially because the application handles clipboard content that may contain sensitive information.

If you discover a security vulnerability, please report it responsibly.

**Preferred method:** Use [GitHub Private Vulnerability Reporting](https://github.com/huynq2311/SlipBoard/security/advisories/new) to submit a confidential report.

Please do not disclose security vulnerabilities through public GitHub Issues or Discussions before they have been addressed.

When reporting a vulnerability, please include:

- A clear description of the issue.
- Steps to reproduce the vulnerability.
- The affected SlipBoard version and macOS version.
- The potential security impact.
- Any relevant logs or proof-of-concept code, excluding sensitive personal data.

## Response and Disclosure

Security reports will be reviewed as soon as reasonably possible.

If a vulnerability is confirmed, we will investigate its impact, work toward a fix, and coordinate responsible disclosure when appropriate.

Please note that SlipBoard is an independently maintained open-source project, so response and resolution times may vary.

## Security Scope

Security concerns may include, but are not limited to:

- Unauthorized access to clipboard history.
- Exposure of sensitive clipboard content.
- Insecure local data storage or encryption.
- Bypasses of application locking or access controls.
- Unintended disclosure of private data.

Thank you for helping keep SlipBoard secure.
